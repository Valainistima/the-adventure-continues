CONTROLS

Controls may vary depending on the emulator core and its settings.

  • Open the EmulatorJS menu to view or change the button mapping.
  • A USB or Bluetooth controller may work if your browser detects it.
  • If the game does not respond, click inside the game area first.

WELCOME, LITTLE DRAGON

Spyro Browser is a fan-made project that runs the classic PlayStation game in your browser using EmulatorJS.

The emulator is loaded from a CDN, so an internet connection is required. Select your own game file from your computer; it is not included in this package.

SAVE YOUR ADVENTURE

Once the game is running, open the EmulatorJS menu and look for Save State / Load State. Availability and behaviour depend on the emulator and its configuration.

The decorative save icon in the artwork does not save the game by itself yet.
